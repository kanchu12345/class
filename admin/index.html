🚀 GitHub Pages Deployment Workflow

How changes make their way to your live website:

  1. When you click Commit & Publish to GitHub, the admin panel creates a new Git commit on branch main updating data/content.json.
  2. Sinhala characters are encoded into UTF-8 safe base64 bytes to guarantee zero text corruption.
  3. GitHub Pages automatically detects the commit and rebuilds the static site within 1–2 minutes.
  4. Visitors on index.html immediately receive the new classes and copy upon refreshing the page.
